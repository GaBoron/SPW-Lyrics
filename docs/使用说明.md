# 使用说明

安装与兼容要求见 [README](../README.md)，遇到异常见[常见问题](常见问题.md)。本页说明当前源码的操作，安装包功能以对应 Release 为准。

## 进入歌词管理

| 入口 | 打开的位置 |
| --- | --- |
| 主窗口顶部「歌词管理」 | 批量管理，可切换手动搜索和元数据编辑 |
| 播放器「更多 → 手动搜索歌词」 | 当前歌曲的搜索与预览 |
| 播放器「更多 → 编辑元数据」 | 当前歌曲的标签、封面和歌词编辑 |

这些入口需要「类变换」权限。标签切换保留候选和草稿；离开管理页或关闭主窗口时，可选择「保存并继续」「放弃修改」或「继续编辑」。停用插件前请先保存草稿。

## 自动加载

启用插件后正常播放即可。没有有效缓存时，插件在后台搜索；先应用通过匹配检查的结果，再按设置升级为更合适的歌词。无可靠结果时保留 SPW 本地歌词，失败结果不缓存。使用默认替换策略并授予曲库权限时，还会按曲库顺序预缓存后续最多 3 首，随机播放不一定命中。

默认类型顺序为 **逐字 → 逐行 → 普通**；同类型按 **AMLL → QQ → 汽水 → 酷狗 → 网易 → Apple Music → LrcShare** 选择。翻译、音译和逐字时间取自所选来源。

LrcShare 需在插件设置中填写自己的 API Key；Apple Music 歌词依赖第三方服务；MusicBrainz 仅提供歌曲元数据，不参与自动歌词选择。

### 本地歌词处理

SPW Lyrics 先检查同名 `.lrc`；不存在时读取内嵌歌词，再尝试同名 `.ttml`。读到 TTML 后直接转换，不等待在线搜索；普通 LRC、普通内嵌歌词交给 SPW，TTML 解析失败时保留原有本地加载流程。

未手动指定在线候选时，本地 TTML 转换优先于自动搜索。想改用在线歌词，可在手动搜索中预览并应用候选。[AMLL into SPW 的本地优先级](#与-amll-into-spw-一起使用)另见下文。

## 自动替换策略

打开「设置 → 创意工坊 → 模组设置 → SPW Lyrics」。下表控制在线歌词的自动加载，本地 TTML 按上一节处理。

| 自动替换歌词 | 行为 |
| --- | --- |
| 始终优先使用插件歌词 | 自动匹配并优先使用插件结果 |
| 仅在本地无歌词时补充 | SPW 未找到本地歌词时才自动匹配 |
| 仅手动选择时替换 | 只应用已手动选择的在线歌词 |

单曲手动选择优先于全局策略。「切回本地歌词」会保持本地歌词，直到点击「恢复自动匹配」。

「歌词选择依据」可选类型优先或来源优先；两者都会检查录音版本。「歌词类型顺序」「歌词来源顺序」从左到右优先，支持逗号、顿号、换行或箭头分隔，例如 `逐行, 逐字, 普通`、`QQ, 网易, AMLL`。

未填写的类型不参与自动选择；未填写的来源不参加自动搜索及「全部来源」手动搜索，仍可手动指定单个来源。名称错误、重复或整栏留空时保留本次会话上一次有效设置；重启后仍无效则暂用默认值。「重置歌词排序」恢复完整默认列表和类型优先模式，重新打开设置可查看。有效修改会重新评估自动缓存，保留单曲手动选择。

## 手动搜索

1. 核对目标歌曲，输入关键词，搜索全部来源或指定来源。
2. 对照歌名、歌手、专辑和时长，点击候选预览。
3. 确认后点击「应用歌词」，或选择「恢复自动匹配」「切回本地歌词」。

候选先显示歌曲信息，再在后台更新实际歌词类型；「未知」表示尚未读到歌词，读取失败可再次点击重试。词源状态的具体原因可悬停查看，失败与超时的处理见[搜索问题](常见问题.md#搜索与匹配)。

可靠的自动结果固定在第一项，标注「自动搜索」，不受手动关键词、来源筛选和列表排序影响；仅预览不会改变单曲选择。「排序」会记住上次选择。预览下方的「元数据查看」可查看并复制候选标签和 TTML 元数据。

切歌后点击「刷新歌曲」或按 `F5`；歌曲不一致时，应用、切换策略和保存延迟会被拒绝。窄页面通过「搜索结果 / 歌词预览」切换查看。

快捷键：`Enter` 搜索，方向键切换候选，`Ctrl+Enter` 应用，`Ctrl+F` 聚焦搜索框。

### 调整歌词延迟

展开「时间调整」，输入毫秒数后保存。**正数延后、负数提前**：歌词早了 500 毫秒就填 `500`。范围为 -60000 到 60000 毫秒，「重置」恢复为 0。

延迟按歌曲保存，同时调整逐行和逐字时间，适用于在线歌词和插件转换的本地 TTML；普通本地 LRC、普通内嵌歌词及纯文本歌词不受影响。保存后没有刷新时，切到其他歌曲再切回即可。

## 编辑歌曲元数据和内嵌歌词

### 打开文件与导入信息

首次进入读取当前歌曲，也可点击「打开歌曲」选择文件。支持 MP3、FLAC、M4A、MP4、OGG、WAV、AIFF；保存目标始终是页面顶部显示的路径，切歌不会自动更换它。

歌曲信息可编辑歌名、歌手、专辑、发行日期等标签，多值字段每行填写一个值。封面支持 JPEG / PNG，单张最多 20 MiB、2500 万像素；替换正面封面会保留其他图片，「移除」清除全部图片，「恢复」回到本次读取时的图片状态。以上操作先修改草稿。

导入在线信息时：

1. 在搜索中选中候选，点击「导入元数据」；也可从编辑页点击「在线匹配信息与封面」搜索当前编辑文件。
2. 勾选所需字段、封面或歌词，选择「仅填补空字段」或「覆盖所选字段」，应用到草稿。
3. 核对内容后再保存。来源的空值不会清除已有内容，详情或封面失败可重试或换候选。

从编辑页发起搜索会保留现有草稿；搜索页的「刷新歌曲」则切回当前播放歌曲。导入候选歌词不需要先将它应用为播放歌词。

### 逐句与逐字编辑

「导入歌词」支持 TTML、LRC、增强 LRC、SPL，文件编码为 UTF-8 或带 BOM 的 UTF-16。在线来源的 QRC、KRC、YRC 也可解析后导入草稿。

- 「添加歌词」在当前句后插入新句；拖动把手调整顺序，不改变时间戳；主句连同背景行移动，背景行也可单独移动。TTML 跨分组移动需在「编辑原文」中处理。
- 时间可填 `mm:ss.mmm`、`hh:mm:ss.mmm` 或毫秒数。行内 `−100` / `+100` 同时平移本句及逐字时间。
- 可编辑正文、翻译、音译，并设置「主唱（左）」「对唱（右）」和「背景人声」。背景行归属前一主句；首行或连续背景行中多出的背景行会作为独立主句保存。
- 替换整句正文会清除该句逐字时间；在逐字列表中改词可保留时间。含注音等嵌套标记的词在逐字区只调时间，文本请在「编辑原文」中修改。

`Ctrl` 点击多选，`Shift` 连选，`Ctrl+Shift` 追加连选；歌词列表中 `Ctrl+A` 全选、`Delete` 删除所选。多选可统一平移时间和设置声部、背景；正文和逐字编辑需切回单句。

同时间戳的原文、译文和可识别音译会自动归类；各自有逐字时间的内容保留为独立句，无法确定时请核对。逐句编辑只更新对应 TTML 节点，保留未编辑的注音、扩展标签和元数据。

### 歌词写入格式

在底部选择「写入格式」，再点击「写入歌曲文件」或按 `Ctrl+S`。首次使用 TTML，之后记住上次选择；无需先转换草稿，即使正文未改也可换格式写入。

| 格式 | 保留内容与限制 |
| --- | --- |
| TTML | 原始 TTML 的完整 XML、逐字时间、声部、背景、翻译、音译、注音和元数据；其他来源可生成 TTML |
| LRC | 逐行时间、正文、翻译和音译，逐字时间降为逐行 |
| 增强 LRC | 用尖括号保留已有逐字时间，逐行来源仍保留逐行时间 |
| SPL | 逐字标记及显式行结束时间 |

LRC、增强 LRC 和 SPL 无法完整表达 TTML 的声部、背景、注音等信息。写入前会列出损失，可继续、改选格式或返回编辑；保存成功后会读回实际内容，恢复丢失信息需重新导入原始歌词。缺少时间轴时请选择 TTML。

### 保存与刷新

「歌词预览」用于核对；确认写入后才修改音频，清空原文再保存可清除内嵌歌词。「保存并继续」同样会写入文件。`F5` 或「重新读取」可重载顶部路径对应的文件，先保留需要的草稿。

保存只更新改过的标签和封面，并校验、读回结果；文件被其他程序修改时需重新读取。占用或保存错误的恢复步骤见[写入问题](常见问题.md#歌曲文件写入失败)。

保存后会尝试刷新歌词；歌名、封面等信息需重新扫描 SPW 曲库。仍显示在线歌词时，选择「切回本地歌词」，并检查同名歌词文件的优先级。

## 跟随宿主播放打轴

在内嵌歌词区进入「打轴」，先让 SPW 播放正在编辑的文件，再点击一个词或「启用键盘」。时间取自 SPW 实际播放位置，录入只修改草稿，完成后仍需写入歌曲文件。

需要分词时点击「自动分词」，可选「CJK 逐字 / 英文音节」或「按空格保留整词」；已有逐字内容保持原样，无法处理的扩展标记会提示。可在跟随所选词与跟随播放之间切换。

| 操作 | 按键 |
| --- | --- |
| 记录词首 | `F` |
| 连续轴：结束当前词，同时开始并选中下一词 | `G` |
| 仅记录词尾并移到下一词，保留停顿 | `H`；下一词开始时再按 `F` |
| 上下词 / 上下句 | `A` / `D`、`W` / `S` |
| 定位上下词 / 本句首尾词 | `R` / `Y`、`Home` / `End` |
| 播放暂停 / 前后 1 秒 | `Space`、`←` / `→` |
| 调整倍速 / 恢复 1× | `[` / `]` 每次 0.05×，`'` 恢复；菜单范围 0.5×～2× |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |

「打轴设置」可选按下、松开或两者中点判定。智能首词、智能尾词默认关闭；开启后，首词的首次 `G` 只记开始，末词的 `G` 只记结束。拖长音可设置「空拍」，对应次数的 `G` 只计数；跳过的句子可通过再次点选恢复。

手动「打轴补偿」范围 -2000 到 2000 毫秒，正数延后。倍速不会缩放歌词时间轴；松开或中点判定期间切歌、跳转会取消该次记录。输入框不接管打轴字母键。

打轴撤销最多保留 100 步；重新读取、保存或在其他模式修改歌词会重置记录。离开打轴、切换工具标签或关闭管理页时，会恢复进入打轴前的倍速。

### 频谱与波形辅助

频谱分析另需安装并启用 **SPW Media Runtime**：Steam 版可从页面点击「在 Steam 中打开」前往 [Runtime 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3824060316)，其他渠道或入口不可用时使用 [GitHub 安装包](https://github.com/GaBoron/SPW-Media-Runtime/releases/latest)。启用后点击「重新分析」。

点击打轴工具栏「频谱」查看波形和逐字边界。滚轮横移，「放大 / 缩小」调整时间窗，「定位所选」回到当前词；点击频谱或波形可定位播放。拖动词块中间平移区间，左右边缘调整词首、词尾，重叠人声分轨操作。松手后提交草稿，一次拖动可整体撤销。

关闭频谱、切页或停用插件会取消本插件的分析；异常和超时处理见[频谱问题](常见问题.md#频谱不可用或分析超时)。

### 鼓点输入延迟校准

在「打轴设置」点击「鼓点输入延迟校准」，选择速度并开始。宿主会暂停；先听 4 拍，再用 `Space` 或 `G` 跟随敲击。16 次机会中至少 12 次有效敲击才可保存，波动过大时重新测量。

输入延迟会按当前判定方式校准，保存后供下次打轴使用，也可手动输入后「保存补偿」。正输入延迟会提前记录：测得 `+80 ms` 时，1× 提前 80 毫秒，0.5× 提前 40 毫秒；它与手动「打轴补偿」叠加。关闭面板停止鼓点，更换输出设备后可重新校准。

## 批量管理音乐库

刷新音乐库后勾选歌曲：

- 「缓存歌词」提前取得歌词，只写插件缓存。默认跳过有效缓存，可选择「重新处理已有缓存」。
- 「批量写入」先选择标签字段、封面或 TTML 歌词，再选择「仅补充空数据」或「覆盖所选数据」，确认后「开始写入」才修改音频。空值不清除已有内容；选中的封面获取失败时，该曲本次不写入音频标签。
- 每首歌右侧的铅笔可编辑歌曲信息；开始批量任务前先确认逐曲编辑的未保存修改。

批量处理使用同一套可靠匹配和排序规则，跳过已有单曲手动选择或本地锁定，最多同时处理 3 首。元数据、封面和歌词取自选中的同一来源。

任务可暂停、继续、停止并重试失败项。切换标签或关闭页面后任务继续，重新打开可看进度；停用插件会停止后台任务。停止会保留已完成的缓存和标签，已开始的文件保存会完成当前事务。批量写入后重新扫描 SPW 曲库，再切歌核对。

## 与 AMLL into SPW 一起使用

同时启用支持 [TTML 互通的 AMLL into SPW](https://github.com/GaBoron/AMLL-into-SPW)，并授予它所需权限，即可接收原始 TTML，保留来源中的逐字、声部、背景、翻译、音译和注音。启用顺序不限，接收器不可用时仍继续提供普通 SPW 歌词。

AMLL into SPW 自己找到的本地 TTML 优先：**同名 `.ttml` → 内嵌 TTML → 同名 `.lrc` 中的 TTML → SPW Lyrics 提供的结果**。想使用在线选择时，需先移走优先的本地 TTML；「切回本地歌词」会撤回外部选择，但不会隐藏它找到的本地 TTML。

单曲延迟单独传递，原始 XML 不变；此偏移只作用于 SPW Lyrics 提供的结果，直接读取的本地 TTML 需调整文件自身时间轴。

## 本地缓存

从插件设置点击「查看本地缓存文件夹」可直接打开 `cache`。数据根目录：Windows 为 `%LOCALAPPDATA%\SPW Lyrics`，Linux 通常为 `~/SPW Lyrics`。

关闭 SPW 后，将要重建的对应缓存移入回收站：

| `cache` 内的位置 | 重建效果 |
| --- | --- |
| `歌词` 中的单曲文件 | 下次播放重新获取该曲歌词 |
| `手动匹配` 中的单曲文件 | 清除该曲手动选择或本地锁定，恢复自动匹配 |
| `AMLL 索引` | 下次需要时重新下载索引 |
| `宿主Hook.properties` | 下次启用重新定位管理页面入口 |

清空整个 `cache` 也会清除单曲手动选择。单曲延迟、打轴输入校准和界面选择保存在缓存目录外，清理 `cache` 不会重置它们。

## 网络与隐私

在线检索会向相应服务发送歌名、歌手、专辑、时长等歌曲信息，预缓存和批量任务会检索各自范围内的歌曲。插件无需登录音乐平台账号，不上传音频或导入的歌词。

自动加载和「缓存歌词」只写插件缓存；编辑页的「写入歌曲文件」、`Ctrl+S`、「保存并继续」，以及批量「开始写入」会修改所选音频文件。
