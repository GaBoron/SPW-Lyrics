# 🛟 常见问题

## 自动加载失败怎么办？

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 手动搜索歌词”，修改关键词或指定一个歌词来源，再选择合适候选。没有匹配成功的歌曲下次播放会自动重试。

## 为什么一直显示 SPW 本地歌词？

网络搜索可能仍在后台进行，也可能所有候选都没有达到可靠匹配标准。插件会优先避免误配，因此不会自动使用明显不可靠的结果。

## 为什么没有翻译、音译或逐字效果？

不同平台和歌曲提供的歌词内容不同。插件会保留来源中可用的信息，但无法生成来源本身没有提供的翻译、音译或逐字时间轴。可以在手动窗口尝试其他来源。

## 歌词已经找到，却没有立即刷新？

自动刷新依赖 SPW 当前的内部实现。如果后续 SPW 版本发生变化，歌词仍会保存在缓存中；重新选择一次歌曲通常即可加载。

## 手动搜索窗口在哪里？

入口是“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 手动搜索歌词”。窗口打开后会自动搜索一次，同一时间只能打开一个。

## 如何查看或清理缓存？

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics”，点击“查看本地缓存文件夹”。关闭 SPW 后，可以自行删除其中不再需要的缓存文件。

## 安装后看不到插件怎么办？

确认导入的是 Release 中完整的 `spw-lyrics-0.1.0.zip`，并且没有提前解压。完成本地安装后重启一次 SPW。当前版本只测试了 SPW `1.16.2` Steam 版和 Windows x64。

## 歌词轴与演唱不匹配怎么办？

插件无法判断不同版本的歌词对应的效果，如果有明显偏差，请前往插件设置手动调整版本源。
