# 🛟 常见问题

## 先判断是哪种问题

- **完全没有歌词**：先看“自动加载失败怎么办”；
- **显示的是另一首歌或错误版本**：看“歌词内容或歌曲版本明显错误怎么办”；
- **文字基本正确，但唱到的位置不对**：看“歌词轴与演唱不匹配怎么办”；
- **缺少翻译、音译或逐字效果**：看“为什么没有翻译、音译或逐字效果”；
- **切歌后仍显示上一首歌词**：看“为什么切歌后还显示上一首歌词”。

## 安装与设置

### 安装后看不到插件怎么办？

依次确认：

1. 导入的是 Release 中完整的 `spw-lyrics-0.3.0.zip`，没有提前解压；
2. 使用的是 SPW 的“设置 → 创意工坊”本地安装或导入模组入口；
3. 安装完成后已经启用了此插件。

当前版本只测试了 SPW `1.16.2` Steam 版和 Windows x64。

### “自动替换歌词”应该怎么选？

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 自动替换歌词”：

- **始终优先使用插件歌词**：每首歌都自动搜索，适合希望尽量使用在线逐字歌词的用户；
- **仅在本地无歌词时补充**：保留内嵌歌词和同名 `.lrc`，仅在本地没有歌词时联网搜索；
- **仅手动选择时替换**：关闭自动搜索，只应用你在手动窗口选择的歌词。

## 搜索与来源

### 自动加载失败怎么办？

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 手动搜索歌词”，然后可以：

- 删除专辑名等多余关键词，只保留歌名和歌手；
- 指定 Apple Music、QQ 音乐等单个来源；
- 对照专辑、时长和匹配分选择候选。

没有匹配成功的歌曲不会缓存失败结果，下次播放仍会自动重试。

### 为什么一直显示 SPW 本地歌词？

常见原因包括：

- 当前替换策略是“仅在本地无歌词时补充”或“仅手动选择时替换”；
- 网络搜索仍在后台进行；
- 所有候选都没有达到可靠匹配标准；
- 这首歌曾在手动窗口选择“切回本地歌词”。

最后一种情况可以在手动窗口点击“恢复自动匹配”，清除这首歌的手动锁定并立即重新搜索。

### 为什么 Apple Music 有歌词，却默认选择了其他来源？

插件先比较歌词类型，再比较来源优先级：

1. 先检查所有来源是否存在逐字歌词；
2. 没有逐字歌词时，再选择逐行歌词；
3. 类型相同时，才按 AMLL TTML DB、Apple Music、QQ 音乐、酷狗音乐、网易云音乐的顺序选择。

因此 Apple Music 只有逐行歌词，而 QQ 音乐等来源存在逐字歌词时，会默认使用后者。

### Apple Music 的曲名、歌手或歌词文字为什么和本地不同？

不同地区的 Apple Music 曲库可能使用不同的曲名、专辑名或歌手写法。插件会适度放宽这些地区差异和歌手别名的匹配，但仍会阻止明显的 Live、Remix、伴奏等版本冲突。Apple Music 返回的繁体歌词会自动转换为简体。

自动匹配仍然失败时，可以在手动窗口直接输入其他地区使用的歌名或更简短的关键词。

## 歌词显示与匹配

### 歌词错误怎么办？

先不要反复重装插件，按错误类型处理：

- **整首歌词都不对**：通常选中了同名歌曲，按下一条重新选择候选；
- **歌名相同但版本不对**：重点核对专辑、时长以及 Live、Remix、伴奏等字样；
- **只有错字、缺行或翻译错误**：换一个歌词来源；
- **文字正确但时间不准**：换来源或换同一首歌的其他候选；
- **仍显示上一首歌**：跳到“缓存与刷新”中的对应问题。

### 歌词内容或歌曲版本明显错误怎么办？

先打开“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 手动搜索歌词”：

1. 对照正在播放歌曲的歌名、歌手、专辑和时长；
2. 预览其他候选，优先选择专辑和时长一致的版本；
3. 如果候选太多，改为只搜索一个来源；
4. 确认内容正确后再点击“应用此歌词”。

常见误选包括同名歌曲、Live、Remix、伴奏、翻唱、重新录音和不同语言版本。匹配分只能帮助排序，不能代替预览确认。

如果已经选错，可以点击“恢复自动匹配”重新搜索，或者点击“切回本地歌词”。

### 歌词本身有错字、缺行或错误翻译怎么办？

这通常是歌词来源中的原始数据有问题，插件不会自行改写歌词内容。可以：

- 在手动窗口预览并改用其他来源；
- 删除这首歌的歌词缓存，让插件重新获取；
- 如果所有来源都有相同问题，前往 [GitHub Issues](https://github.com/GaBoron/SPW-Lyrics/issues/new) 反馈。

反馈时请提供歌名、歌手、专辑、歌曲时长、当前歌词来源和问题截图。无需粘贴整首歌词。

### 为什么翻译有错误，对不上歌词轴或缺少一部分？

这可能是插件获取翻译时：

- 获取了错误的翻译来源；
- 翻译的时间轴与歌词时间轴有较大差异；
- 翻译来源将某句歌词拆分/合并翻译导致配对偏差。

### 为什么没有翻译、音译或逐字效果？

- AMLL 或 Apple Music 的主歌词缺少翻译时，插件会尝试从 QQ 音乐、酷狗音乐或网易云音乐补充；
- 如果匹配的其他来源同样没有翻译，插件不会自行生成；
- 逐字时间轴和音译必须由歌词来源提供。

手动窗口中的“逐字”“逐行”“普通”来自歌词实际解析结果，可以据此尝试其他候选。

### 歌词轴与演唱不匹配怎么办？

这通常是同名歌曲、不同专辑版本或时长接近的 Live、Remix、伴奏版本被选中。打开手动搜索后：

- 对照候选的专辑和时长；
- 尝试指定单个歌词来源；
- 预览确认后再应用候选。

如果歌词文字正确、但所有候选的时间轴都存在相同偏差，通常是来源本身的时间轴问题。请改用其他来源，或按上一条说明提交问题信息。

## 缓存与刷新

### 歌词已经找到，却没有立即刷新？

自动刷新依赖 SPW 当前的内部实现。如果后续 SPW 版本发生变化，歌词仍会保存在缓存中；重新选择一次歌曲通常即可加载。

### 为什么切歌后还显示上一首歌词？

依次尝试：

1. 切换到其他歌曲，再切回当前歌曲；
2. 打开手动窗口，点击“恢复自动匹配”；
3. 关闭 SPW，删除当前歌曲对应的“歌词”和“手动匹配”缓存文件；
4. 重启 SPW 后重新播放。

如果仍然复现，请反馈前后两首歌的信息、操作顺序和截图，以便判断是缓存键、自动刷新还是 SPW 接口行为导致。

### 如何查看或清理缓存？

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics”，点击“查看本地缓存文件夹”：

- “歌词”保存自动及手动加载的歌词，删除后会在下次播放时重新获取；
- “手动匹配”保存每首歌的手动选择，删除后会恢复自动匹配；
- 文件采用“歌手 - 曲名”命名，可以在关闭 SPW 后按歌曲删除。
