# 使用说明

本文只介绍插件的实际使用方式。构建、Provider 和 Workshop API 相关内容见 [开发与构建](开发说明.md)。

## 自动加载

启用 SPW Lyrics 后正常播放歌曲即可。没有可用缓存时，插件会在后台搜索歌词；搜索期间 SPW 可以继续显示内嵌歌词或同名 `.lrc`。

自动结果先比较歌词质量，再比较来源优先级：

1. 逐字歌词
2. 逐行歌词
3. 普通歌词

歌词质量相同时，来源顺序为：

1. AMLL TTML DB
2. Apple Music
3. QQ 音乐
4. 酷狗音乐
5. 网易云音乐

匹配时会综合歌名、歌手、专辑和歌曲时长，并尽量排除明显的 Live、Remix、伴奏、翻唱等版本冲突。

首次搜索不会无限等待所有来源。插件会在约 10 秒内先应用当时最合适的结果，剩余来源继续在后台完成；如果之后找到更高质量或同质量但优先级更高的歌词，缓存和当前歌词可能再次更新。缺少翻译时也可能在主歌词显示后继续补充。

如果所有来源都没有可靠结果，插件会保留 SPW 本地歌词，并提示尝试手动搜索。失败结果不会写入歌词缓存，下次播放仍会重新尝试。

## 自动替换策略

进入“设置 → 创意工坊 → 模组设置 → SPW Lyrics → 自动替换歌词”可以选择：

- `始终优先使用插件歌词`：每首歌都自动搜索并优先使用插件结果。
- `仅在本地无歌词时补充`：优先保留 SPW 的内嵌歌词或同名 `.lrc`，本地没有歌词时再搜索。
- `仅手动选择时替换`：关闭自动搜索，只使用手动选择过的歌词。

单曲的手动选择优先于全局策略。某首歌手动选择“切回本地歌词”后，也会保持本地歌词，直到你在手动窗口恢复自动匹配。

## 手动搜索

可以从插件设置点击“打开手动搜索”，也可以使用 SPW 中配置的“打开歌词搜索”快捷键。默认快捷键为 `Ctrl+Shift+M`。

窗口打开后会使用当前歌曲信息进行搜索。你可以：

- 修改搜索关键词；
- 搜索全部来源或指定一个来源；
- 查看候选的歌曲名、专辑、时长、歌词类型和匹配分；
- 预览候选歌词后再应用；
- 恢复自动匹配；
- 切回 SPW 本地歌词；
- 取消插件从其他来源补入的翻译。

候选中的“逐字”“逐行”“普通”来自歌词实际解析结果，不依赖搜索接口的预估类型。手动选择会按歌曲保存，不会被之后的自动搜索覆盖。

手动窗口同一时间只会打开一个实例，并会记住上次位置。显示器布局变化后，窗口会尽量回到可见区域。

如果快捷键无效，请先检查 SPW 的插件权限和快捷键设置。快捷键的自定义、冲突处理和全局绑定由 SPW 负责。

## 批量处理音乐库

第一次使用插件，或一次加入了很多歌曲后，可以打开“批量处理音乐库”提前建立缓存。

批量处理会读取 SPW 已扫描的音乐库，使用与自动播放相同的匹配和歌词选择规则，但不会修改音频文件或 SPW 音乐库本身。

使用时可以：

- 只勾选需要处理的歌曲；
- 默认跳过已有缓存，或选择重新处理；
- 暂停、继续和停止任务；
- 处理完成后单独重试失败项。

批量处理最多同时处理 3 首歌曲。相同录音会尽量复用同一份搜索结果，避免重复请求。界面会显示总体进度和单曲状态，包括搜索歌词、选择结果、补充翻译和写入缓存等阶段。

停止任务不会删除已经成功写入的缓存。没有可靠匹配的歌曲也不会写入错误结果，之后正常播放时仍会重新搜索。

## 支持的歌词内容

插件可以处理 TTML、QRC、KRC、YRC 和 LRC，并尽量保留来源中已有的：

- 逐字或逐行时间轴；
- 翻译；
- 音译；
- 对唱；
- 背景歌词；
- 同一时间播放的多行歌词。

插件不会自行翻译歌词，也不会生成来源中不存在的音译。

当 AMLL 或 Apple Music 的主歌词没有翻译时，插件可以尝试从 QQ 音乐、酷狗音乐或网易云音乐补充。补充翻译如果不合适，可以在手动窗口点击“取消补充翻译”；该操作只移除插件跨来源补入的翻译，不影响歌词来源原本提供的翻译。

## 本地缓存

插件缓存默认位于：

```text
%LOCALAPPDATA%\SPW Lyrics\cache
```

也可以在插件设置中点击“查看本地缓存文件夹”直接打开。

缓存目录中主要包含：

- `歌词`：自动或手动取得的歌词；删除后，下次播放会重新获取。
- `手动匹配`：每首歌的手动选择；删除后，该歌曲恢复自动匹配。
- `AMLL 索引`：AMLL TTML DB 的本地索引缓存；删除后会在需要时重新下载。

修改或删除缓存文件前建议先关闭 SPW，避免和正在进行的搜索或写入同时发生。

## 网络与隐私

在线搜索时，插件会把当前歌曲的歌名、歌手、专辑和时长发送给相应歌词服务。批量处理时，会对所选歌曲逐首发送这些信息。

插件通过 SPW 的曲库接口读取歌曲元数据，不需要登录 QQ 音乐、网易云音乐、Apple Music 等账号，也不会读取、修改或上传本地音频文件内容。
