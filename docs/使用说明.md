# 📖 SPW Lyrics 使用说明

## 自动加载歌词

安装插件后正常播放歌曲即可。SPW Lyrics 会按以下顺序寻找歌词：

1. AMLL TTML DB
2. QQ 音乐
3. 酷狗音乐
4. 网易云音乐
5. SPW 本地歌词

插件优先使用逐字歌词，其次是逐行歌词和普通歌词。自动匹配会同时参考歌名、歌手、专辑和本地歌曲时长；遇到明显的 Live、Remix、伴奏、翻唱或时长差异时，会避免直接套用错误歌词。

如果所有网络来源都没有可靠结果，插件会保留 SPW 的内嵌歌词或同名 `.lrc`，并提示你尝试手动搜索。没有匹配成功的结果不会缓存，下次播放还会重新尝试。

## 手动搜索歌词

入口：

> **设置 → 创意工坊 → 模组设置 → SPW Lyrics → 手动搜索歌词**

窗口打开后会自动搜索当前歌曲。你可以：

- 修改搜索关键词；
- 搜索全部来源或只搜索一个来源；
- 查看候选歌曲、专辑、时长、歌词类型和匹配分；
- 预览候选歌词；
- 把任意候选应用到当前歌曲；
- 切回 SPW 本地歌词。

手动选择的来源会持续保存。同一时间只会存在一个手动搜索窗口，多次点击入口会回到已有窗口。

## 支持的歌词内容

SPW Lyrics 可以处理 TTML、QRC、KRC、YRC 和 LRC，并尽量保留：

- 逐字或逐行时间轴；
- 翻译；
- 音译；
- 对唱；
- 背景歌词；
- 同一时间播放的多行歌词。

实际显示内容取决于歌词来源是否提供相应数据。插件不会自动生成来源中不存在的翻译或音译。

## 本地缓存

已成功加载的歌词会缓存 30 天；用户手动选择的来源和“切回本地歌词”会持续保存。

查看缓存入口：

> **设置 → 创意工坊 → 模组设置 → SPW Lyrics → 查看本地缓存文件夹**

默认数据位置：

```text
%LOCALAPPDATA%\SPW Lyrics
```

## 网络与隐私

搜索歌词时，插件会把当前歌曲的歌名、歌手、专辑和时长发送给所选歌词服务。插件不需要你登录音乐账号，也不会读取或上传你的音乐文件内容。
