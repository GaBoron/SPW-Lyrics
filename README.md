# SPW Lyrics

`spw-lyrics` is a lyrics enhancement plugin for Salt Player for Windows.

The `0.1.0` MVP targets automatic and manual lyrics loading from AMLL TTML DB,
QQ Music, Kugou Music, NetEase Cloud Music, and SPW's built-in local lyrics
fallback.

## Build

```powershell
.\gradlew.bat test plugin
```

The installable archive is written to `build/plugin/`.
