# 常见问题

如果你只是想了解插件怎么用，先看 [使用说明](使用说明.md)。这里主要处理安装、匹配、刷新和缓存问题。

## 安装后看不到插件

先确认安装包和 SPW 版本是否匹配。

`1.2.0` 的 `.spmod` 安装包需要 SPW 1.19.0 / Workshop API dev23 / JVM 25。SPW 1.18 用户请使用 [v0.4.0](https://github.com/GaBoron/SPW-Lyrics/releases/tag/v0.4.0)。安装包直接导入，不要解压。

然后依次检查：

1. 安装包没有被提前解压或重新打包。
2. 使用的是 SPW“设置 → 创意工坊”的本地安装或导入入口。
3. 安装后插件已经启用。
4. SPW 更新后如果插件仍未出现，重启一次 SPW 再检查。

反馈时请注明 SPW 和插件版本；无法加载时可暂时停用插件，换回与宿主版本匹配的安装包。

## 打开歌词管理时崩溃

如果报错包含 `UnsatisfiedLinkError` 或 `RenderNodeContext_nMake`，可能是渲染接口与 SPW 的原生渲染库不匹配。关闭 SPW，安装与宿主匹配的完整插件包，再重启 SPW 后打开歌词管理；已加载的渲染库需要重启才能替换。

仍然崩溃时，可暂时停用插件，并反馈操作系统、SPW 和插件版本及完整异常。不要自行替换 SPW 安装目录中的 DLL 或 `.so` 文件。

## 顶部没有歌词管理图标，或主窗口入口未启用

先检查插件是否获得“类变换”权限，授予后重新启用插件。主窗口结构无法唯一识别或 Hook 安装失败时，插件会提示原因，请反馈 SPW 版本和完整异常。

如果问题出现在 SPW 更新后，请反馈 SPW 版本和完整异常，使用与宿主匹配的已发布版本或等待修复。动态发现能适应重命名，但不保证任意页面结构变化后都能继续接入。

## 自动加载失败

先打开手动搜索，确认是否能找到正确候选。可以尝试：

- 缩短关键词，只保留歌名或歌名加歌手；
- 指定单个歌词来源；
- 对照专辑和时长选择候选；
- 检查网络是否能访问相应歌词服务。

自动匹配失败不会缓存失败结果，因此不需要为了“清掉失败缓存”反复重装插件。

## 一直显示 SPW 本地歌词

常见原因有：

- “自动替换歌词”设置为“仅在本地无歌词时补充”或“仅手动选择时替换”；
- 这首歌之前手动选择过“切回本地歌词”；
- 在线来源暂时还没有得到可靠结果；
- 所有候选都没有通过匹配检查。

如果是单曲手动锁定，在手动搜索标签页点击“恢复自动匹配”即可清除该选择并重新搜索。

## 歌词是另一首歌，或版本不对

打开手动搜索后，重点核对候选的专辑、时长以及 `Live`、`Remix`、`Instrumental` 等版本信息。匹配分只用于帮助排序，不应替代实际预览。

常见误选包括同名歌曲、现场版、混音版、伴奏、翻唱、重新录音和不同语言版本。确认正确候选后再点击应用。

如果所有候选都不对，可以提交 Issue。请附上歌名、歌手、专辑、歌曲时长、当前歌词来源和问题截图，不需要粘贴整首歌词。

## 为什么某个来源有歌词，却选了其他来源

插件先比较歌词质量，再比较来源优先级。

例如 AMLL 只有逐行歌词，而 QQ 音乐找到了逐字歌词时，会选择 QQ 音乐；只有歌词质量相同时，才按 AMLL TTML DB、QQ 音乐、酷狗音乐、网易云音乐的顺序选择。

## 文字正确，但时间轴不对

这通常是同一首歌的不同录音版本被匹配到，或者歌词来源本身的时间轴存在偏差。

先在手动搜索中对照专辑和时长，再尝试同一首歌的其他候选或其他歌词来源。如果多个来源都有相同偏差，再考虑反馈来源数据问题。

如果整首歌只差一个固定时间，可以在右侧歌词预览下方调整“歌词延迟”。正数延后，负数提前；点击“保存延迟”按歌曲保存，或点击“恢复 0 ms”取消。延迟调整不能修复随播放逐渐增大的偏差，也不适用于普通本地 `.lrc`。

## 缺少翻译、音译或逐字效果

翻译、音译和逐字时间轴由当前歌词来源提供。缺少这些内容时，可以在手动搜索标签页预览并换用其他来源。

## AMLL into SPW 没有显示所选的 TTML

先确认两个插件都已启用，AMLL into SPW 支持 TTML 互通，并已获得它需要的权限。后启用插件时会自动重新提供当前歌曲，不需要固定启用顺序；仍无变化时，可切到另一首歌再切回来。

AMLL into SPW 自己读取的本地 TTML 优先于在线选择。检查歌曲旁边的 `.ttml`、音频内嵌 TTML，以及内容为 TTML 的 `.lrc`；优先级和延迟作用范围见 [使用说明](使用说明.md#与-amll-into-spw-一起使用)。如果想撤回外部选择，在手动搜索标签页点击“切回本地歌词”；存在优先的本地 TTML 时仍会显示它。

SPW Lyrics 会持续向 SPW 提供普通歌词，供灵动词岛等插件读取；AMLL into SPW 的接收器不可用、拒收或报错时，也可使用这些歌词。普通歌词显示与原生 TTML 不同，并不表示缓存丢失；缺少原始 XML 的旧 TTML 缓存会重新获取。若只有某一份 TTML 无法原生显示，请对照其他候选，并反馈两个插件版本和歌曲信息。

## 找到歌词后没有立即刷新

插件会先写入缓存，再请求 SPW 重新加载当前歌词。刷新失败时会自动再试一次。

如果歌词已经写入缓存但界面没有变化，可以先切到另一首歌再切回来。如果 SPW 更新后持续无法自动刷新，可能是宿主接口发生变化，请提交 Issue 并注明 SPW 版本。

## 切歌后仍显示上一首歌词

按下面顺序排查：

1. 切到其他歌曲，再切回当前歌曲。
2. 打开手动搜索标签页，点击“恢复自动匹配”。
3. 关闭 SPW，删除当前歌曲对应的歌词缓存和手动匹配记录。
4. 重启 SPW 后重新播放。

如果仍能稳定复现，请记录前后两首歌的信息和操作顺序，并附截图反馈。

## 如何清理缓存

从插件设置点击“查看本地缓存文件夹”。

- 删除 `歌词` 中对应文件后，下次播放会重新搜索。
- 删除 `手动匹配` 中对应文件后，该歌曲会恢复自动匹配。
- 删除 `AMLL 索引` 后，插件会在需要时重新下载索引。

建议关闭 SPW 后再手动删除文件。

默认缓存目录为：

```text
%LOCALAPPDATA%\SPW Lyrics\cache
```
